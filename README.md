# KLiK

KLiK is a Flutter dating app prototype with profile discovery, Likes, chat, and profile editing.

## iOS demo

<video src="docs/media/klik-ios-demo.mp4" controls width="320"></video>

[Open or download the iOS demo video](docs/media/klik-ios-demo.mp4)

The video was recorded on the iPhone 17 Pro Simulator running iOS 26.3. That simulator runtime has a known emoji rendering issue, so emoji may appear as question-mark boxes in the recording.

## Run locally

```sh
flutter pub get
flutter run
```
